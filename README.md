# Bild-Studio DE/EN (Homelab-Kompass)

Bilingual Runpod template for current ComfyUI image models: **Krea 2 Turbo** (optional **Krea 2 RAW**) and **MOSS-Image SFT** including the official edit LoRA. Builds on the official Runpod ComfyUI image (ComfyUI 0.44.0, CUDA 12.8), adds German and English docs, official ComfyUI workflows, download-on-start, a prompt filter required by the Krea 2 Community License, and secure password defaults. No model weights are shipped in the image.
